# Documentation

This directory contains project documentation, organized by stage and purpose:

## Directories

- **`brd/` (Business Requirements Documents)**  
  Ideas and high-level business requirements describing *what* needs to be built and *why*.  
  *Naming example:* `BRD001-runtime-metrics.md`

- **`prd/` (Product Requirements Documents)**  
  Detailed product and technical requirements used as actionable input for coding agents describing *how* features should be implemented.  
  *Naming example:* `PRD001-metrics-collector.md`
